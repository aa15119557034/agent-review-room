# 世界可玩版本：任务与验收

2026-11-16，林离。依据：[ADR-008](design/ADR-008-世界-第一版.md)（#227 已合并）、[世界启动分工](世界-启动.md)。江浩已确认“按这个方案来，继续推进，做出能玩的版本再验收”。

## 完成口径

交付能启动、能点击、能共同生活并恢复进度的版本。内部 mock、规则日志和阶段性 PR 不作为最终验收。用户操作以 ADR 开头 10 项为准；工程故障验证见 [世界验收场景](世界-验收场景.md)，两者都完成后再交江浩。

画面按已确认的开罗式清楚布局与《动森》式生活感结合，复杂度随实际开销调整。场景 CPU/GPU/内存、素材与加载、模型调用分别记录，不将轻量 2D 当作未经实测的性能保证。

## 接入范围

沿用现有依赖方向：core 的确定性规则 → db 的原子提交 → main 的世界服务。没有新增 package 或通用任务调度器；节点调用复用文本 Run 传输，不直接调用会写聊天、笔记或媒体记录的 ChatService。

世界后台新文件按启动分工由林离实现。必要既有入口预计涉及 `packages/core/src/index.ts`、`packages/db/src/index.ts`、`packages/db/src/migrations.ts`、desktop `main/ipc.ts`、`main/index.ts`、`main/workspace.ts`；实施 PR 逐项说明由 C酱审查。preload 已有通用 `command/query/onEvent`，不另开世界频道。迁移号以合并时的最新版本为准，当前为 v26。

模型和网络不进入 SQLite 事务；提交成功后才通知 UI。备份先关闭世界生产入口，再等待已接纳写入收束，再进同一写队列制作快照。暂停、重置、恢复与资料切换的代次和用户意图按 ADR 执行。

exit 0

这仅证明数据库基础测试环境可用，不证明世界实现、真实模型、GUI 或性能已验收。后续各 PR 记录自己的实际命令、输出、版本和未覆盖项；不把这里的基线成绩重复当作新功能成绩。
