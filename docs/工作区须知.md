## 3. 连接 GitHub（本机没装 `gh`）

- 远端：`https://github.com/aa15119557034/agent-review-room.git`
- 每个 shell 先设 `$env:GCM_INTERACTIVE = "never"`，否则凭据管理器弹窗会卡住自动化
- 提交身份是空的，**每次提交都要带**：
  ```powershell
  git -c user.name='汐' -c user.email='deepseek@agent-review-room.local' commit -m "[汐] D-xx ..."
  ```
- 开 PR / 读评论用 REST API（没有 `gh`）：

```powershell
$nl = [Environment]::NewLine
$inp = 'protocol=https' + $nl + 'host=github.com' + $nl + 'username=aa15119557034' + $nl + $nl
$out = $inp | git credential fill 2>&1
$pass = ((($out | Where-Object { $_ -match '^password=' }) -replace '^password=','') -join '').Trim()
$h = @{ Authorization = "Bearer $pass"; 'User-Agent' = 'dsh'; Accept = 'application/vnd.github+json' }

# 开 PR
$payload = @{ title = '[汐] D-xx 标题'; head = 'deepseek/D-xx-简述'; base = 'main'; body = (Get-Content pr-body.md -Raw) } | ConvertTo-Json -Depth 3
Invoke-RestMethod 'https://api.github.com/repos/aa15119557034/agent-review-room/pulls' -Method Post -Headers $h -ContentType 'application/json; charset=utf-8' -Body ([System.Text.Encoding]::UTF8.GetBytes($payload))

# 读评论
Invoke-RestMethod 'https://api.github.com/repos/aa15119557034/agent-review-room/issues/88/comments' -Headers $h
```

> token 只在内存里用，**不打印、不落盘、不进 PR**。

## 4. 本机环境坑

| 坑 | 症状 | 解法 |
|---|---|---|
| 继承了 `ELECTRON_RUN_AS_NODE=1` | 启动桌面端报 `Cannot read properties of undefined (reading 'isPackaged')` | 先 `Remove-Item env:ELECTRON_RUN_AS_NODE` |
| `pnpm setup` 撞内置命令 | `Unknown option: 'recursive'` | 用 `pnpm --filter @room/agent-server run setup`（**要有 run**） |
| 后台作业跑服务器 | 会话结束进程跟着死，或退出码 `4294967295` 但进程还活着 | 服务器放**独立 PowerShell 窗口**跑 |
| 中文进管道 | PS 5.1 下变 `?` | 用 PowerShell 7；测试命令用英文 |

本机节点启动：

```powershell
cd E:\agent-review-room\dev
$env:DEEPSEEK_API_KEY = [Environment]::GetEnvironmentVariable('DEEPSEEK_API_KEY','User')
pnpm --filter @room/agent-server run start      # 127.0.0.1:7420
```
