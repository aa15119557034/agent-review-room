# ADR-006：资料与维护

- 状态：实现提案，待 PR 评审与用户合并；不代表 Phase 1B 真机验收通过。
- 日期：2026-11-04
- 作者：林离（Codex）
- 依据：issue #193 全项目评审及 S1–S10 建议；江浩在本次会话明确要求“功能补充这些你直接做，推送上去”。本任务由 Codex 跨 schemas / db / desktop 实现，契约与实现分两个 PR，按顺序合并。

## 决定

沿用现有 Electron main、SQLite、WriteQueue 和控制面 API，在设置里增加“资料与维护”，不增加独立架构服务。人工决定只是带版本的记录，不触发批准、定稿或执行。

| 建议 | 实现范围 |
|---|---|
| S1 | 根目录 verify 入口覆盖 9 组测试、9 组类型检查及两个构建；Windows CI 输出同样的结果 |
| S2 | 构建写版本与 commit；轻量打包跳过语音大资源；检查 ASAR、原生 SQLite、ASR / TTS sidecar |
| S3 | 读取节点 health 与本机资源状态；配置存在和真实试跑成功分开显示 |
| S4 | 白名单诊断 JSON：版本、状态、任务关联 ID、时间；不导出聊天、Prompt、地址、路径、凭据 |
| S5 | 数据库一致性快照及全部引用媒体备份；校验后恢复到新目录；预览后按范围导出 Markdown 与附件 |
| S6 | README、任务板、统一验收记录与使用说明同步，真实未验收项保留 |
| S7 | 消息、议题、方案、笔记统一查询、分页、来源详情及成果导出 |

| S10 | 聊天、讨论与媒体任务统一历史/活动列表，实际时间、失败原因及已有媒体取消入口 |

## 契约与权限

类型只在 packages/schemas/src/workspace.ts 定义；命令、查询注册在 control-api.ts。维护和文件操作需要 admin，决定保存需要 author，读取遵循现有 reader 权限。renderer 不传本地文件路径；main 使用系统文件/文件夹选择对话框。新增协议不包含隐式后台执行。

搜索用创建时间和 kind:id 稳定游标；每页最多 50。详情重新校验可见性，撤回的用户消息及其回复不返回，引用撤回资料的聊天材料/聊天笔记不进入该资料索引。人工决定来源只能来自同议题可见消息，选择器显示最近 200 条。

## 数据与恢复

DB v25 只增加不可更新/删除的决定版本表。备份在写队列中确认无活动任务、无转写后用 VACUUM INTO 产生快照；对数据库、images / files / audio 的引用字节逐一做 SHA-256 校验。缺失、损坏、链接路径、目录逃逸、重复清单、过新版本拒绝。临时目录失败即清理，验证后发布新目录。

备份保留数据库历史审计内容，不能作为公开分享包；本机配置、凭据、外部模型和 Python 环境不备份。恢复复制到新目录，写恢复来源标记；打开副本再次校验当前数据库与引用附件，并由本机对话框确认重启切换。原始备份不能直接作为活动目录。已使用过的副本按当前数据库校验，不再要求它与原始备份 hash 相同。可切回默认资料目录。

分享导出先展示准确内容与附件清单，再校验预览 digest；内容变化要求重新预览。导出不含运行快照、节点记忆正文和本机配置。最多 10000 条资料、5M 字符，超限明确报错。可选是否复制附件。

## 限制与后续

搜索是 SQLite 字面子串查询，尚无 FTS；万条聊天基准写入验收记录，真实大库仍需测量。大备份同步复制期间可能阻塞桌面，暂不新增后台进程。方案对照保留相同首尾，中间按整段增删显示，不是逐词语义差异。健康检测不调用真实模型、ASR、TTS 或出图。

PDF/Word 解析、插件框架、自动执行和已暂停的订阅画图不纳入本轮；需另外立项。issue #193 的原有缺陷仅本轮依赖的 GitHub dispatcher 注入、ASR 打包路径随实现修复，其余评审缺陷不因本 PR 自动关闭。
