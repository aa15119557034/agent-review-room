## 行为

项目/讨论页可以准备一次公开资料检索：先显示原样查询、已配置节点地址、profile、最多 1 次 Search + 1 次 Fetch 和未知费用；批准后才调用节点。准备只做 health 检查，绝不调用 Search/Fetch。查询上限为 128 个 Unicode 码点，不发送项目历史、笔记、附件或讨论内容。

沿用 Snapshot → Approval → Run。v29 只为已有快照增加不可变 research_plan/research_hash，为 Run 增加一次性的原件关联；旧记录保持空值。主进程在批准和实际发送前复核 hash、当前目标和两项能力。普通批准、批量批准、普通 Reviewer 路由不能消费检索计划。

节点在研究模式下缓冲可读 citation 和 usage，子进程成功关闭后按 seq 先发完整 message_complete，再发引用及终态。主进程核验正文 UTF-8 字节数及 SHA-256，以同一事务写 source_input、自引用、Run 原件关联和事件。收到过早引用会永久拒绝该 seq；重复事件须与已有内容相同。原文最多 512 KiB，不裁剪或归一化换行。

原文查询限定项目内已有 message/snapshot 的引用位置，每次重查当前来源。历史 reference 保留，撤回或缺失时正文为空；私有聊天须经过已有显式分享边界。界面将标题、原文作为纯文本显示，切项目、切库及撤回时清除旧预览。原文保存后可手动选择片段，绝不自动加入讨论。

取消/切库会先使捕获的上下文失效，等待 health 或写队列的旧工作不能晚到写入。已提交的原文在后来失败/取消时保留，Run 仍按实际状态结算，不产生 reviewer_output。不自动重试付费启动或恢复中断检索。
