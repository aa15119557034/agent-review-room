# P2-S07 首片：项目资料的独立 Search / Fetch 生产端

作者林离，C酱评审。按 [#259 合并后分工](https://github.com/aa15119557034/agent-review-room/pull/259#issuecomment-6926178061)，本片有 `apps/agent-server/` 目录例外。使用已合并的 P2-C11 展示契约和 P2-D08 项目原件存储；不新增 wire 类型。

## 本片交付

`bin/deepseek-search-fetch.mjs` 作为既有 RemoteRun 的子进程运行，单个已批准的检索词执行一次 Search、最多一次 Fetch，不调用模型、不自动重试。检索词就是 `snapshot.content`（1–128 个 Unicode 字符），正文 hash 仍由既有 StartRun 边界核对。不能把完整评审 Prompt 发到这个 profile。

新 profile 用 `searchFetch: "deepseek-v1"` 和 `parser: "room-jsonl"` 显式声明；health 只对这些 profile 声明 `structuredResults.version=1`。每次 Run 还必须显式 opt-in，否则在调用付费服务前拒绝。旧 profile 不接受新开关，也不发送展示事件。节点配置或继承环境不能伪造每次 Run 的协商变量。

只支持项目/讨论资料，不接 chat、world、图片、附件、模型选择或聊天记忆。Search `count=1, need_content=false`；只把 Fetch 的完整 `content` 作为 `message_complete.text`，不会将摘要、标题或文件 ID 当成原件。可读引用的 version/hash 都是这份正文的 UTF-8 SHA-256。没有结果时明示没有可读原件；Fetch 失败时引用为 missing、hash/version 为 null，Run 失败。

取消、并发槽、lease、重连重放和最终状态复用 RemoteRun。异步校验后再次核对 Run ID，避免同时重试绕过幂等而多发付费请求；重放不会再次访问厂商。终态以后不发布新正文或展示事件。

## 限制与访问边界

- 仅向固定的官方 `https://api.deepseek.com/v1/tools/search`、`/v1/tools/fetch` 发送请求，节点不直接请求搜索结果 URL。节点本地 CLI 的 `--base-url` 只允许官方地址或显式 `http://127.0.0.1` 测试端点，不来自远端请求。
- 候选 URL 只接受无凭据的 HTTP(S) 标准端口域名，拒绝 IP 字面量及常见本地名称。这只是语法筛选，**不是 DNS 检查或访问授权**；实际目标和跳转政策由 Fetch 服务执行，403 明示拒绝。服务 HTTP 重定向不跟随。
- 每次 HTTP 超时 30 秒，JSON 响应最多 2 MiB，正文最多 512 KiB；超限失败，不截断后冒充完整原文。UTF-8/JSON 损坏失败。
- 密钥仅在节点环境/既有 `envFiles` 中读取。错误不回传厂商错误体或底层异常，避免泄漏请求和凭据。402/429 走既有 `quota_exhausted`；不自动重试。
- `toolCalls` 是节点观察到的 HTTP 工具调用尝试次数；不是计费回执。厂商没有返回 token/金额时，均为 `unknown/not_reported`，不填 0，也不把公开单价估算写成实测费用。

API 形状与价格于 2026-11-17 核对 [DeepSeek 官方 Search & Fetch 文档](https://api-docs.deepseek.com/guides/search/)。成功且非空的调用分别为每千次 0.75 美元；错误、空结果及超时的计费以服务端规则为准，取消后是否已扣费仍可能未知。

## 节点配置示例

在已有配置的 `profiles` 中手工增加独立项目 profile，路径换为实际安装目录；本 PR 不改本机正在运行的节点配置。既有节点安装流程会复制 `bin/`。

```json
{
  "deepseek-research": {
    "command": "C:/Program Files/nodejs/node.exe",
    "args": ["E:/agent-review-room/node/app/bin/deepseek-search-fetch.mjs"],
    "cwd": "E:/agent-review-room/node/deepseek/chat-sandbox",
    "parser": "room-jsonl",
    "searchFetch": "deepseek-v1",
    "envFiles": { "DEEPSEEK_API_KEY": "deepseek-api.key" },
    "maxIdleTimeoutMs": 90000,
    "maxTotalTimeoutMs": 120000
  }
}
```

如节点必须经代理，按本机 Node 的实际代理支持单独放行相应环境变量；不在代码中写死代理，不自动改网络或安全设置。

## 入库和界面接线尚未完成

本片是**生产端**，真实测试使用隔离 harness 将原件写入 D08 的 `source_input`，并验证备份重开。它不等于桌面端已经能点按钮检索。

接线时必须先固定当前项目/数据库/Run，等待完整正文和成功终态，核对引用 hash/version，再存原件。本生产端的 citation 先于 `message_complete` 到达；D08 的 sink 要求可读原件已经存在，不能把网络事件直接全部喂进去。下一片需明确批准检索的桌面命令、原件与展示事件提交顺序、取消/切库后的拒收，以及主进程预览查询的小契约，再落实现。不要自行扩展 renderer IPC，也不要让 renderer 写入可信网页元数据。

聊天网页来源的存储、会话归属与读取契约仍待单独冻结；文档上传、模型内置搜索、自动循环和完整 P2-X12 不在本片。
