# 世界 3D：角色与光影制作口径

## 已确认的方向

2026-11-16，江浩再次确认“开罗和动森风格”，并补充“建模是高模带光影的，不是一些粗糙的低模”。开罗提供紧凑俯视、房间与活动可读性；动森提供温暖的日常氛围、圆润且精致的造型。两者在真实 3D 小屋中结合，具体效果以近景与全景实机为准。

“圆润”不是低细节、同一底模换衣服颜色，也不强制幼儿体型。角色设定图中的发型、面部、服装结构和标志性饰物要能认出来；人物、家具、材质和光线需要统一。

## 制作与验收

1. 保存可编辑模型源文件与可复现构建脚本；导出实际带骨骼的 glTF/GLB。人物轮廓、头发分束、衣领、袖口、裙褶、饰物和鞋面有立体结构，面部从侧面仍成立。细分数量只是制作数据，不代替视觉质量。
2. 近景区分皮肤、头发、布料、金属、玻璃等材质。灯光要有方向和柔和过渡，脚底、衣物叠层及家具接触处有合理阴影；避免高曝光抹掉服装细节和面部。
3. 全景能辨认人物和生活活动；对话近景仍是同一个房间与模型。默认俯视取景减少空旷留白，保留手动旋转、缩放及回到全景。
4. 坐、读、做饭、吃饭、睡眠、走动需要实际检查变形和接触关系；不允许腿被沙发前板遮成断肢、袖口脱离手臂或发饰穿脸。先前的坐面/座深根因修复保留。
5. 性能优化从合批、贴图尺寸、阴影距离/分辨率和渲染分辨率入手。按本机实际帧率与资源记录选择档位，不能用“优化”把用户要求退回粗糙低模。高精度源模型与运行资产的面数、体积、材质数量分别记录。
6. 新四居民+玩家、旧八居民+玩家、对话和 960×760 窗口都要覆盖。固定渲染场景与真实后台分别验证；图像样片不等于模型、交互、存档和最终美术验收全部完成。
