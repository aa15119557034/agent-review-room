# 桌面端安装包与语音包（Python + 模型）

> 江浩 2026-11-03 定的方式：**exe 只装程序本体（200~400MB），语音资源按 zip 解压进去，后面补丁也走 zip。**

## 产物（都在 `release/`）

| 文件 | 内容 | 大小 |
|---|---|---|
| `评审室 Setup <版本>.exe` | 安装程序本体（`resources/app.asar` + runner.py） | 200~400MB |
| `tts-runtime-<版本>.zip` | Python、site-packages（torch 等）、IndexTTS2 代码、`tts/runtime.json` | 约 7GB |
| `tts-model-IndexTTS-2.zip` | 模型权重、`tts/models/IndexTTS-2/model.json` | 约 10.6GB |

两个 zip 都是 **zip64**（7-Zip 和 Windows 自带解压都能读）。

## 安装

1. 双击安装包，装到任意目录（默认不需要管理员权限）。
2. 把两个 zip 解压到 **`%LOCALAPPDATA%\评审室\`**（推荐；解压后出现 `%LOCALAPPDATA%\评审室\tts\`）。也支持解压到安装目录（`<安装目录>\tts\`），但**升级 / 卸载会被 NSIS 清掉**，见下面「卸载」。
3. 启动程序，日志里会有一行 `[tts] 语音包：<路径>（runtime=1，model=indextts2-2.0.0）`。

没解压 / 解压不全 / 版本不对时，日志会明确说是哪一步（「语音包没装」「缺 site-packages」「版本不对」），**不会**报一串 Python 错误。

> 也兼容旧的 `<安装目录>/resources/tts` 布局；优先用 exe 旁边的 `tts`。

## 打包

```powershell
# 先出两个语音包 zip，再出 NSIS 安装包（都放 release/）
pnpm --filter @room/desktop run pack

# 只出免安装目录（win-unpacked），验证布局用（不跑 NSIS）
pnpm --filter @room/desktop run pack:dir
```

源目录默认 `E:\AI\TTS`，可以用 `TTS_BUNDLE_DIR` 覆盖。需要四样：

- `pythons/cpython-3.11.13-windows-x86_64-none`（base Python）
- `index-tts/.venv/Lib/site-packages`（torch 等依赖）
- `index-tts`（代码，打包时排除 `.venv`）
- `models/IndexTTS-2`（权重）

脚本会校验、暂存到 `apps/desktop/vendor/`（已 gitignore），用 7-Zip 打 zip，然后跑 `electron-vite build` + `electron-builder`。

**不需要 electron-rebuild**：better-sqlite3 v13 是 Node-API prebuilds（`prebuilds/win32-x64.node`），Electron 直接能加载；`electron-builder.yml` 里 `npmRebuild: false`。

## 怎么打补丁 / 装补丁

- 程序本体的小更新：只重新打一个程序 zip（主要是 `resources/app.asar`，几十 MB），用户解压覆盖安装目录即可；不用重新装 18GB。
- 只换依赖：重新发 `tts-runtime-<新版本>.zip`；只换模型：重新发 `tts-model-IndexTTS-2.zip`。版本号写进对应 `runtime.json` / `model.json`，程序启动时读出来——版本不对会明确提示重新解压。
- 版本号同时要改 `apps/desktop/src/main/tts-paths.ts` 里的 `TTS_RUNTIME_VERSION` / `TTS_MODEL_VERSION`（程序按这两个值校验）。

## 卸载 / 升级

- electron-builder 的 NSIS 卸载脚本会 `RMDir /r $INSTDIR`，**而且装新版本 exe 时会先静默跑旧版卸载器**——所以放在安装目录里的东西（包括 `<安装目录>\tts`）升级一次就没了。
- 因此语音包推荐放在 **`%LOCALAPPDATA%\评审室\tts`**（安装目录外面）。`deleteAppDataOnUninstall: false` 让卸载器不动 `%APPDATA%` / `%LOCALAPPDATA%`，升级 / 卸载后语音包都还在。
- 解压到安装目录仍然能用（兼容），但要接受升级后重新解压。

## 已知限制

- 语音包很大（合计约 18GB），网盘/传输要注意；zip 用「不压缩存储」是为了打包快，要省空间可以自己用 7-Zip 重压。
- 首次合成要加载 10.6GB 模型，`tts.ts` 的 `loadTimeoutMs` 默认 120 秒。
- 新机器上没有 `userData/tts.json` 时，自带配置的 `voices` 是空的——「播放」会提示选声音；设置里有没有这个入口还没确认（记待办）。
