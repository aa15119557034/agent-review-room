# 任务板 · Phase 1B：外观、聊天空间、参与者、工作部分

依据：`docs/design/ADR-002-讨论室模式.md`、`docs/design/ADR-003-聊天空间.md`（提议中）。
顺序按用户 2026-10-23 的选择：外观 → 聊天空间 → 参与者（控制台、额度、替补）→ 工作部分。

可以并行（汐评审意见）：C-32 → D-30、C-39 → D-33 不必等外观验收，可以和 C-34 同时进行。

| 并行道 | 任务 | 估算（汐） |
|---|---|---|
| A | C-32 → D-30、C-39 → D-33 | 1～1.5 天 |
| B | C-34 → D-31a → D-31b → D-31c | 4～6 天 |
| C | C-36 → D-32 → X-32 | 2～3 天 |
| 贯穿 | 迁移真库副本、重启读回、e2e | 1～2 天 |

每个小阶段都要用户验收后再进入下一个。契约（C-）都是单独 PR，用户合并 = 批准。
