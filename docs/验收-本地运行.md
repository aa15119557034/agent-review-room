# 在干净机器上跑起来（现场测试用）

> 给 C酱 / 林离 在另一台电脑上拉代码、跑起来、改东西。语音包（约 18 GB）不在仓库里，见最后。

## 需要

- Windows 10/11，能开窗口（Electron 44）
- Node.js 22.x、pnpm 10、Git
- 聊天要一个 `DEEPSEEK_API_KEY`（只在本机节点进程里用）

## 拉代码

```powershell
git clone https://github.com/aa15119557034/agent-review-room.git
cd agent-review-room
git switch main
pnpm install
```

> 仓库是私有的，用你自己有权限的 GitHub 账号/token。

## 跑桌面端（开发态）

```powershell
pnpm -C apps/desktop dev
```

- 数据在 `%APPDATA%\@room\desktop`（`settings.json` / `room.db` / `tts.json`）
- 设置页 → 节点：填本机节点地址和 Token（见下）
- 设置页 → 导入包：没有语音包时两项显示「未安装」，不影响聊天/评审

## 本机节点（聊天用）

```powershell
$env:DEEPSEEK_API_KEY = [Environment]::GetEnvironmentVariable('DEEPSEEK_API_KEY','User')
pnpm --filter @room/agent-server run setup -- --local
pnpm --filter @room/agent-server run start
```

- `setup` 会打印地址和 Token；地址默认 `http://127.0.0.1:7420`，Token 填进设置页的「主控机（汐）」
- 聊天的 profile 是 `deepseek-chat`，讨论是 `deepseek-discuss`；两个都要在节点配置里

## 语音包（可选，不在 git 里）

两个 zip：`tts-runtime-1.zip`、`tts-model-IndexTTS-2.zip`（共约 18 GB）。

解压到安装目录旁的 `tts\`（打包版）或 `%LOCALAPPDATA%\评审室\tts\`，目录里应有：

```
tts/python/python.exe
tts/site-packages/
tts/index-tts/
tts/models/IndexTTS-2/
tts/runtime.json          {"version":"1"}
tts/models/IndexTTS-2/model.json   {"version":"indextts2-2.0.0"}
```

设置页「导入包」也可以直接把 zip 导进去（逐行「导入 zip」；带 `pack.json` 的新 zip 才支持顶部自动识别）。

开发态（`pnpm dev`）不会自动找 `tts/`；要用语音得在 `userData/tts.json` 里写 python/脚本，或者直接测打包版。

## 无界面自检（打包版）

```powershell
.\评审室.exe --self-test
.\评审室.exe --import-local-token controller-local
.\评审室.exe --set-voice deepseek xiaoyu
.\评审室.exe --tts-test "你好，我是汐。"
```

- `--self-test`：JSON 报告（数据目录、包状态、TTS 包、节点 Token + `/v1/health`）；退出码 0 = 已配置的东西都正常，1 = 有坏了（没装语音包 / 没配节点不算失败）
- `--import-local-token`：从 token 文件导入本机节点 Token（主进程里加密，和界面「一键导入」同一条路；节点必须先出现在节点列表里）
- `--set-voice` / `--tts-test`：给参与者设声音、跑一遍合成，验证语音包

## 打包

```powershell
pnpm -C apps/desktop exec electron-builder --dir
```

产物在 `apps/desktop/release/win-unpacked`；带语音包的安装包见 `docs/封装-安装包.md`。

## 这台验收机器上的坑（其它机器一般没有）

- 环境变量 `ELECTRON_RUN_AS_NODE=1` 会让 exe 当 Node 跑：启动前 `set ELECTRON_RUN_AS_NODE=`
- 受限进程写不了 `C:\Users\...`（含 `%TEMP%`）：可用 `AGENT_REVIEW_ROOM_DATA` 把数据目录指到可写位置
- Chromium 沙箱在这台机器上需要 `--no-sandbox`
