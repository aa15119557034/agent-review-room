# 资料与维护

入口：设置 → 资料与维护。演示模式没有本地维护能力，请使用桌面后端。

## 查资料与导出

“搜索与成果”支持全部资料、议题或聊天范围的字面关键词查询。点击结果查看全文，Agent 回答可继续查看实际来源。撤回内容不会进入搜索或分享导出。

选择单个范围后点击“预览并导出这个范围”，检查文字和附件，选择是否包含附件，再选择目标文件夹。输出为资料.md、资料清单.json 及可选附件目录。清单保存原始文件名、引用和 hash，附件使用安全引用名；不会因为文件名覆盖别人的文件。预览后资料变化会要求重新预览。

## 方案、决定与任务

方案对照可选择两个版本，红色移除、绿色新增，中间变化整段展示。待决定事项可记录采纳、拒绝、延后及理由，绑定同议题来源。保存是追加版本，其他窗口先保存时会拒绝旧版本覆盖。这里的采纳不会自动定稿或执行。

任务页可查看三类任务的排队、实际起止时间和失败原因；没有开始时间时不推测剩余时间。媒体任务支持已有取消命令，聊天任务可查看对应的输入快照。页面提供手动刷新和历史分页。

## 健康与诊断

节点“连接可用”只说明 health 返回；媒体“已配置，未试跑”不表示生成一定成功。诊断预览只含版本、状态、任务 ID 和时间，不包含聊天、Prompt、节点记忆、地址、路径或凭据。回答来源中的完整输入是另外一个本地查看入口，不进入诊断导出。

## 备份与恢复

1. 停止运行/排队任务，等待录音转写完成，点击“备份资料”。选择保存位置，应用创建新的备份目录，不覆盖已有资料。
2. 备份包含数据库和引用的图片、文件、原始录音、合成音频。数据库保留历史审计资料，请妥善保管。密钥、本机配置、模型与 Python 环境不包含；更换电脑或切换目录后可能需要重新配置节点与媒体。
3. “校验备份并恢复为副本”先校验全部文件和数据库，再复制到一个新目录。缺失或损坏即失败，当前活动数据库不变。
4. “打开恢复副本并重启”只接受通过恢复入口建立的副本，确认后切换。不要直接打开原始备份。“切回原资料并重启”返回应用默认资料目录。

大备份期间界面可能暂时没有响应；不要强制结束应用。备份目录里的 manifest.json 用于不可变备份验证；恢复副本使用 restore-origin.json 标识，后续使用可以合法改变数据库。

## 开发验证与打包

依赖已安装时从仓库根目录运行：

~~~sh
node scripts/verify.mjs
node scripts/verify.mjs tests
node scripts/verify.mjs types
node scripts/verify.mjs build
~~~

结果写 .verification/summary-<mode>.json 和各组日志。all 覆盖 schemas、core、db、reviewer-client、remote-client、agent-server、desktop、renderer、e2e；Windows CI 使用同一入口。

~~~sh
pnpm -C apps/desktop pack:app --dir
pnpm -C apps/desktop verify:artifact ../../release/win-unpacked
~~~

pack:app 跳过两个大型语音包，仍构建应用本体；正常打包仍沿用原流程。verify:artifact 只验证包内容和构建来源，不替代实际启动、安装/升级、录音、TTS 或 GPU 出图验收。真实结果统一记入 Phase1B-验收记录.md。
