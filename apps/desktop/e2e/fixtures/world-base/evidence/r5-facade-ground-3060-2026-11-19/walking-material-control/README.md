# 第三人称步行的同进程材质对照

在同一个 1440 × 900 的 RTX 3060 Laptop 场景里，从车站出生点真实按住 W 约 3.3 秒。每段走了 10.03–10.09 米。每种着色先在 C 后巷预热，确认四个公寓材质都实际绘制，再回到同一起点。旧着色复用同帧像素对照的还原方法，移除第 5 轮背光项，并把 AO 强度恢复到 0.65。候选恢复交件的着色和 0.4 AO。正常的世界更新和动画全程运行。

| 不加 GPU 计时查询，按执行顺序 | 实测平均 FPS | 帧时 P95 |
| --- | ---: | ---: |
| 旧着色 1 | 65.00 | 15.5 ms |
| 第 5 轮 1 | 64.70 | 15.5 ms |
| 第 5 轮 2 | 64.70 | 15.5 ms |
| 旧着色 2 | 51.82 | 30.8 ms |

另四段以相同顺序插入 WebGL 计时查询，每五帧采样一次，从车站更新到场景和后处理绘制结束。GPU 区间中位数依次为 14.29、14.46、14.78、14.46 ms。两种材质下，每帧主相机都提交了四个公寓材质，每种各一次。去掉第 5 轮着色也出现了 30.8 ms 慢帧。此前独立启动时，两次候选实走的 P95 仍应记录为 30.8 ms。

[硬件、坐标、绘制次数与逐段统计](report.json) 中的 `raw` 字段指向各段原始间隔、GPU 读数和真实按键记录。运行 `node walk-material-probe.cjs <Electron文件> <world-base目录> <含baseline和acceptance-transport的world-base目录> <新的输出目录>` 可复测。
