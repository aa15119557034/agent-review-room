# C酱 第 9 轮：暗部黑点 + AO 条带

源码只改 `src/look.js`。云端 SwiftShader，960×600，1.6 m 眼高（`eye.cjs`，23/24 用 `stats.view` + fov 55）。

**注意：云端连不上 dl.polyhaven.org，本轮截图里的塑料箱和卷帘用的是替身**（同尺寸、同三角数的盒子，单色贴图；卷帘 diff 为 sRGB #555a60）。
卷帘真实贴图下的效果要林离在本机复测，不能拿这些图当卷帘验收。

1. 暗部：上游 `(col-.5)*uContrast+.5` 在线性空间以 .5 为支点，1.05 时 <0.024 全部变负再被夹成 0。
   改为 x≥0.12 照旧，x<0.12 用幂函数 toe `y0*(x/x0)^p`，在 x0 处值和斜率都接上（p = c·x0/y0）。
   纯黑仍是 0，暗部比例保留；默认 contrast 仍 1.05，街道和店内中高亮度不变。
   林离给的像素 .0070 → toe 后约 .0029，再经既有暗部抬升 +.012，约 sRGB 30 左右（原为 0）。
2. AO：原来的成对深度测试会在前景物体后面的背景上画一圈台阶状光环（信箱、店招、阳台下），
   原因是采样点一跨到前景物上就整项计入，16 个固定采样各自在固定像素距离开关。
   改为用深度重建视空间位置和法线，只在两个表面「互相朝向」时计遮蔽：
   采样点要高于中心所在平面，且中心要在采样点所在平面的前方。墙角、檐下两条都满足；
   信箱/扶手/绿篱站在墙前时，它们正面朝相机、背对后面的墙，第二条不满足，所以不再有光环。
   两个因子在采样点滑过折角时都连续地降到 0，没有逐采样开关的台阶。
   `aoV1-diff-x6-*` 是 AO 开减关放大 6 倍：遮蔽只剩在折角处，对照 `../textured-props-2026-11-17/ao/` 的旧图。
   强度：v1 在折角最多暗约 7–10%，偏弱，终版把系数 3.5→6（`*-final.jpg`）。
3. 暖光：试了只改颜色的预设（太阳 #ffcf9a 2.0、半球 #b4c4ec/#9c8a80 0.92），见 `warm-trial-*`（左现状右暖光）。
   天空和烘焙地形仍是正午，整体只是变暗变紫，不像傍晚，**没有提交**。要做真正的傍晚得一起换天空和 uLightTex 烘焙方向。

验证：`pnpm install --frozen-lockfile && node scripts/verify.mjs`，Linux 20 步全部 code 0，1507/1507 测试通过。
