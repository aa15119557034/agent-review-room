# C酱 第 21 轮：远处道口光晕（#254）

左 = 第 20 轮（`e78c52c`），右 = 本轮，默认傍晚，云端 SwiftShader 960×600，裁切后放大。

上游 `crossing/glow.js` 让光晕在远处保持至少 7 px，航拍时五个道口光晕被 bloom 晕成一块红橙斑。本轮在 `evening-glow.js` 的 `fadeDistantCrossingHalos` 里保留最小尺寸，但按「被放大了多少」降低亮度：`vKeep = mix(0.12, 1, 实际尺寸 / 最小尺寸)`。按原尺寸显示的近景光晕不变。

云端粗计（R>170、G<110、B<110 的像素）：30-aerial 77 → 38，01-street 191 → 172。剩下的主要是灯体和红色招牌。精确开关对照以 3060 实测为准。
