# r13 真机验收（3060，2026-11-20）

改前 `b4abad9`（r9d）/ 改后 `fd7b35b3`（r13，叠在 r12 调色之后）。

**按 C酱 要求：`?grade=off` 关掉第 12 轮调色**，只比连续网格这一改动。基线对 `grade` 无影响，同一参数一起跑。

## 口径

- 原生 Electron 44.9.0 / ANGLE + D3D11 / 1440×900 / DPR 1 / 离屏
- 黄昏固定时钟 `?time=evening&grade=off`
- **时钟彻底冻结**（`tools/preload-freeze.js`，dt≡0）：上一轮教训，不冻结会被动画相位污染
- 帧时：每帧 GPU 合计 P95，预热 60 帧，3 轮取中位

## 结论

### 1. B 平台接缝：硬边消失

跨接缝（y=665/675/685 三条横剖面，x 555–605）**相邻像素最大跳变**：

| | y=665 | y=675 | y=685 |
|---|---|---|---|
| 基线 | 83.6/255 | 44.1/255 | 34.5/255 |
| r13 | **1.9/255** | **2.2/255** | **1.0/255** |

从 84 降到 2，硬边没有了。放大对照见 `zoom-B-seam-r13.png`（左基线 / 右 r13）。

### 2. 没有浮空

合并网格 2980 顶点，抽样 332 个逐点比较「顶点 Y − 正下方地面 Y」：

| 指标 | 值 |
|---|---|
| 最小 / 中位 / P95 | **0.020 / 0.020 / 0.020 m** |
| 最大 | 8 m（8 个点） |

那 8 个 8 m 的点**全部是未被三角形引用的残留顶点**（`referenced: false`），不参与绘制。可见网格的离地高度统一是设计值 0.020 m。

### 3. 回归：其余机位零差异

| 机位 | 变化率 | 说明 |
|---|---|---|
| C 后巷 / E 港镇 / F 山坡 / G 铁路 / H 北端 | **0.000%** | 逐像素完全一致 |
| A 主街 | 0.280% | bbox y 530–663，门前光斑 |
| B 便利店 | 2.114% | bbox y 596–763，平台光斑 |

近白像素（三通道 ≥250）：只有 D 新增 344，其余机位 **新增 0**。
