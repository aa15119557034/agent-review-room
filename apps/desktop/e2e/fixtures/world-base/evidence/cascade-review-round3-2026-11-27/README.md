# 峡谷瀑布第三轮下午复拍

同一相机和景深下对照第二轮与第三轮。Electron 以 1440 × 900 渲染，动画固定在 5 秒。

- [峡谷全景](overview-comparison.jpg)和[瀑布岩岸](pool-comparison.jpg)展示降亮后的暖米岩层。下午用四档宽岩带，细纹从岩面颜色和法线中减淡。落水雾在下午略提亮。
- [半山岩檐](leaf-detail-comparison.jpg)展示同系偏深的岩色、去掉悬空石尖后的左端，以及沿石层压扁的接触阴影。
- [拍摄与检查记录](capture.json)包含相机、33 株植被落点、港镇逐像素对照及页面和 WebGL 检查。

性能沿用 C酱在第二轮通过的结果。本轮按评审范围复拍三个下午机位。
