# C酱 第 20 轮：樱冠、阴面、远处灯（#254）

每张图左 = 第 19 轮傍晚（`6e6d3eb`），右 = 本轮，两边都是默认傍晚。云端 Chromium + SwiftShader，960×600，像素比 1；公寓墙面和道具用的是替身贴图，帧时不在云端测。

- 樱冠（`evening-glow.js` `applyEveningSakura`，只改 `sakura:blob` / `sakura:cards`）：在线性空间里给绿通道设下限（0.42·红），蓝通道保持略高于绿。粉色本体（约 1/.48/.60）基本不变，直射的橙红（约 1/.2/.12）拉回粉色。见 `01-crown-crop`。
- 阴面：傍晚 HemisphereLight 从 `#a8b4ec/#8a6e5c ×0.95` 改为 `#b4bce8/#a08068 ×1.6`，阴面墙抬亮，黑色楼梯和栏杆能从墙上分出来。真实 PBR 抹灰比替身深，以 3060 实拍为准。
- 远处灯：`applyEveningGlow` 不再加亮饱和色灯（道口、车尾的红灯，最小分量 / 最大分量 < 0.6），航拍站区的红橙光斑消失。
