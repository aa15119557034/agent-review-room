# 峡谷瀑布第二轮复拍与帧时

第一轮与第二轮同机位对照见[峡谷全景](overview-comparison.jpg)、[瀑布岩岸](pool-comparison.jpg)、[半山岩檐和垂叶](leaf-detail-comparison.jpg)。两轮下午实景均冻结在动画 5 秒。第二轮另有[傍晚复拍](evening.jpg)。

本轮给崖壁重做暖灰米色与冷蓝灰阴影，沿层理压深岩缝。水束亮边包住略透的中心，落点的六张软雾片合为一次绘制，水面上有向外扩散的破碎白浪环。半山岩檐沿原崖壁嵌入，两簇 Blender 逐片建模的垂叶越过岩沿。三块岸台的几何和位置沿用上一轮，平滑了法线和面色。

下午和傍晚的页面、场景及 WebGL 检查通过。33 株植被支撑检查无跳过，四座岩台共 662 个三角面。第一轮与第二轮的下午港镇对照帧逐像素一致。岩台和灌木源文件在 Blender 重新打开后逐字节复现 GLB。见[场景与相机记录](capture.json)。

首轮计时在 A 和 G 分别测得约 +0.82 ms 和 +0.53 ms。逐帧绘制记录显示，A 和 D 的常规帧多提交了 10 次绘制和 81,129 个峡谷三角面。之后把峡谷专用材质、岩台、叶簇和雾片一起限制在视锥交到峡谷的近处相机。实拍的 12 帧在切换前后逐像素一致。见[切换前帧时](before-isolation-summary.json)和[切换前后像素校验](isolation-capture-parity.json)。

完成峡谷绘制剔除后，原八机位的绘制工作量和着色器均与主干相同，但 H 中值高 0.374 ms。H 同页面把选择回调暂时旁路，保留当下材质和可见状态。正常与旁路的三轮结果分别为 10.162/9.463、9.936/10.154、9.706/9.135 ms。Electron 在六段都完成并输出数据后，关闭时打印一条 GPU 通道警告。见[H 开关原始数据](h-selector-control.json)。

另将相机选择移到渲染调用之前，重新测了十机位。这次复测没有显示整体收益。PR 保留按实际渲染相机选择材质的实现，交付的运行时代码与实测 5ff4870f 逐字节一致。见[前移选择的实测](selector-timing-trial.json)。

## GPU 渲染帧时

RTX 3060 Laptop，1440 × 900。主干 3cf1e324 与候选 5ff4870f 在同批三轮交错运行。每视角预热 60 帧，每组 118 个有效 GPU 计时样本，表中值为三轮 P95 的中位数，单位 ms。A–H 用傍晚光，两个峡谷机位用下午光。A–H 的地形与海面着色器源、defines 与灯光标记在三轮里都与主干逐字节一致。表里的 A–H 严格看候选 ≤ 主干，两个峡谷机位各看候选 ≤ 16.7 ms。GPU 时间来自 WebGL 计时查询。
