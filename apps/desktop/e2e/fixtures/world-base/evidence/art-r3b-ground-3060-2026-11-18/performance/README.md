在此目录执行 `node recompute.cjs` 可从 [匿名原始数据](frames.json.gz) 重算[汇总](comparison.json)。原生重放使用工作树环境变量 `R3B_ORIGINAL`、`R3B_NEW`，以及 `R3B_ELECTRON`（项目 Electron）和 `R3B_OUTPUT`（已存在的输出目录）。两个工作树都需要准备 fixture 的本地资产。按顺序对 `01-original`、`02-r3b`、`03-r3b`、`04-original` 各执行一次 `node replay.cjs <轮次>`。重放入口记录 RAF、实际相机、按键、站区合批和设备时钟；本次原测另并行记录了 Windows 前台和 CPU。
