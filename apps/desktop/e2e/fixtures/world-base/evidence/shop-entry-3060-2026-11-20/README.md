# 洗衣店可进入（附加可走区 + 地形地面 + 室内碰撞）

C酱 方案：主矩形之外用「附加可走区」，不改 `WORLD.play`，不动 `clipMaterials`。

## 三步

**① 附加可走区**（`shop-entry.js` → `walkExtrasFromRooms`）
- 从 `ctx.services.shopInteriors` 里带 `frame` 的房间推出附加区，不写死坐标
- `station.walkExtra` + `station.clampWalkable(position, radius)`：主矩形与附加区取并集
- 洗衣店：`x -2.2…6.2`、`z -125.39…-96.5`（站区局部）

**② 附加区物理地面改用岛屿地形**（`addTerrainWalk`）
- 站区内物理地面与地形平均只差 0.26 m，主矩形外差 **−3.06 m**
- 沿 z 每 2 m 铺 `addWalkRamp`，两端取 `island.heightAt`；边界再补一段接缝斜坡
- 共 15 段斜坡

**③ 室内碰撞**（`addRoomCollision`）
- 由 `shopRoom` + `entrances` 推导：后墙、左右墙、带门洞的前墙
- 门洞碰撞口 = 视觉门宽 + 0.4 m（玩家半径 0.3 m，严格按门宽留口只剩 0.6 m，容易卡边）
- 洗衣店 7 面墙

## 注意

- 北边界没有整体外推：只有洗衣店门口这 8.4 × 29 m 一条附加区可走，边上其他地方仍不可走
- 上游 8 家店的 box 是 lot 局部坐标（无 `frame`），本轮跳过，另开一轮
- 第三人称进屋后会不会卡墙：**未测**（本轮相机只做到台阶与门口）
