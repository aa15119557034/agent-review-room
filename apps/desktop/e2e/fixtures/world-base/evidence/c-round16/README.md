# C酱 第 16 轮：镇边草 / 花 / 绿篱配色，站侧砾石尺度

接第 15 棒评审里归 C酱 的那一项。云端 SwiftShader 960×600；每张对比图左边是改前（`2d3a9ba`），右边是本轮。

## 改了什么

- **镇内和镇边的草地**（`look.js`，`main.js`）
  - 新加一块世界坐标矩形 `uTownRect`。它由 `city.vegetationClearAreas` 的外接框换算到世界坐标得到，向外 12 m 开始过渡，到 55 m 回到原样。
  - 只在这个范围内：
    - 草叶 `vTint` 和地形草皮 `meadowTint`：饱和度降到 62%，色相往橄榄偏，亮度 ×0.9。
    - 花朵：数量保留约 1/4（新加的独立 hash，和原有排名、物种都不相关）。
    - 远处的花色铺面：×0.25。
  - 岛上其他地方不变。
  - 实现方式：
    - Petalwake meadow 的材质是按需创建的。所以在 `Shell.prototype.material` 外面包一层，并把已创建的材质换掉。这个包装只装一次。
    - 每个改动点都用 `insert()`；上游着色器里找不到对应位置就直接抛错。
  - `look.setTownGreenery(rect, 0)` 可以整体关掉，方便对照。
- **城镇的绿篱、灌木和两棵庭院树**（`city.js`）
  - 只改城镇自己的 `M.foliage` 克隆，车站的不动。
  - 链式保留原来的 foliage 叶团补丁：
    - 顶点色饱和度降到 62%，往橄榄偏；
    - 叶团明暗从 +10% / −14% 加到 +16% / −26%，让团块能看出来，不再像光滑的一整块。
  - program key 另起 `…|town-foliage`。原补丁的位置找不到时会抛错。
- **车站侧院的砾石**（`station.js`，也就是 23 服务角）
  - `st-gravel` 贴图 `repeat` 设为 1.9，石子缩到原来的一半左右。
  - 这张贴图另一个用处是西侧小院，在 01 画面里看不到。

## 没动

- 太阳、天空、烘焙光照、全局光。
- 几何和三角形数：镇边仍是 29,933。
- 不新增贴图或像素。
- 墙材质、店招、周转箱。

## 结果

- 20 / 21 / 24：草地从荧光绿收成橄榄绿，花只剩点缀，主次回到建筑和道具上。
- 21 / 24：绿篱有了叶团的明暗。
- 23：砾石变细。看整张图不明显，看裁切对比。
- 04 店内：改前改后只有 18 个像素有差别。
- 01：差别集中在樱花树冠（风动画相位不同）。这和我前两轮之间的云端随机差异是同一量级（C13 对 C14 也有 2.2 万像素差），以林离 3060 上的整张 PNG 对照为准。
