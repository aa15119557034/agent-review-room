# evidence/ 目录规范与测量纪律

> 每轮真机验收在这里建一个 `<轮次>-3060-<日期>/` 目录。这份文件规定目录里必须有什么、
> 数字怎么测才算数。规范优先于个人习惯；和本文冲突的旧目录按当时口径保留，不追溯修改。

## 一、两条硬纪律

### 1. 只报同批次前后对照，不跨批次比绝对值

同一份代码、同一台机器，不同时间测出来的差别可以到 3 ms 以上。

**实证**：同一个 `?shadow=static` 模式，G 铁路机位

| 批次 | P95 |
|---|---|
| 11-20 上午（#268 测量） | 11.36 ms |
| 11-20 中午（三档对照） | 14.40 ms |

差 3 ms，代码和模式完全相同。原因是机器状态（当时 C酱 的虚拟机持续占用约一颗 CPU 核）。

**因此**：结论只能来自「同一批次里 A 和 B 交替测」；跨批次只能比方向，不能比数值。

### 2. 每次记录测量时刻和机器状态

至少记这几项，放进当轮 README 的「测量环境」一节：

- 测量时刻（`yyyy-MM-dd HH:mm`，本地时区）
- GPU：温度、功耗、SM 时钟、`clocks_throttle_reasons.active`（`0x1` 是空闲，正常）
- 是否有重负载进程（例如虚拟机、其他构建/渲染任务）
- 显示与缩放（复制/扩展、分辨率、DPI）

## 二、每轮目录必须包含

```
<轮次>-3060-<日期>/
  README.md          必填，按下面的模板
  tools/             本轮用到的脚本（可复制，也可指向共享目录）
  *.json             原始测量数据（帧时、比对结果）
  *.png / *.jpg      关键对照图（整图可选，裁切图和差异图必须有）
```

## 三、已知的坑（遇到就往这里补）

| 坑 | 表现 | 做法 |
|---|---|---|
| **着色器告警** | 两次跑都测出 0 条 X4000，误以为没问题 | 必须 `--disable-gpu-shader-disk-cache`；GPU 着色器缓存会让程序不重编译，告警不出现 |
| **逐像素比对** | 同一份代码两次差 30%，看着像回归 | 必须冻结时钟（`requestAnimationFrame` 时间戳 + `performance.now` 固定成常数）；不冻结时风/水/花瓣相位不同 |
| **离屏抓图** | `toDataURL` / `readPixels` 拿到全黑 | preload 里强制 `preserveDrawingBuffer: true`，否则合成后画布被清空 |
| **帧时口径** | P95 帧间隔同代码两轮差 15 ms | 用每帧 GPU 合计时间（`EXT_disjoint_timer_query_webgl2`），不用 rAF 间隔 |
| **近白像素** | 调色后 25% 像素都算近白，判据失效 | 分全图 / 天空区（上部 40%）/ 地物区（下部 60%）三个数报 |
| **网格坐标** | 浮空检查算出离地 0.6 m 的荒唐值 | 读 `geometry` 顶点要乘 `matrixWorld`，否则是局部坐标 |
| **静态阴影** | 以为 static 只渲一次，其实每 30 帧还在重渲 | 数 90 帧的 `renderer.info.render.calls` 分布，不要靠读代码判断 |

## 四、共享工具

工具放在仓库外的本机目录（`x51-tools/`），每轮按需复制进 `tools/`：

| 脚本 | 作用 |
|---|---|
| `x51-capture.cjs` | 离屏逐机位截图 + 绘制调用/三角面 + 世界坐标投影 |
| `preload-capture.js` / `preload-freeze.js` | 强制 preserveDrawingBuffer；后者额外冻结时钟 |
| `x51-real-probe.cjs` | 每帧 GPU 合计时间（P50/P95）+ 预热 60 帧 |
| `compare-pair.py` | 两组截图逐像素比对 + 近白像素三区统计 |
| `x51-diff.py` | 带区域统计和裁切图的专项比对 |
| `x51-float*.cjs` | 光斑离地的几何实测 |
| `x51-shadowcount.cjs` | 数每帧绘制调用，判断阴影 pass 是否发生 |
| `x51-phases.cjs` | 按渲染阶段拆 GPU 时间（全开/关阴影/关后处理/关倒影） |
| `analyze-style.py` | 画风指标（P05/P95/饱和/色阶档数） |
| `summarize-*.py` | 各轮汇总脚本 |
