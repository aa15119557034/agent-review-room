# 地面全屏合成的采样与深度

独立性能试装 `1347d29d`，基于第四轮远山之前的最终广场樱花。世界照常使用四重抗锯齿和可采样深度。当前景层只有一张全屏三角形时，合成目标使用单采样颜色。场景在该层加入锐利模型时，会恢复四重采样和 24 位深度。

RTX 3060 Laptop 上，主街 A 单次全屏绘制的 GPU 中位耗时从 **0.299 / 0.299 毫秒**降至 **0.059 / 0.060 毫秒**。采样以原版、试装、试装、原版顺序交错，定时查询未发生 disjoint。这部分收益不足以让独立原生进程的主街和两段步行连续达标，改动留在试装分支。[GPU 查询及逐帧数据](gpu/timers.json)

## 同一帧比较

先实际绘制世界，再让原始提交中的完整合成函数与试装函数处理同一张 RGBA16F 世界颜色、同一张深度和同一份上一帧相机矩阵。两次都照常运行后处理，随后回到原实现复查。原始参考模块直接取自 Git。八个玩家高度机位，加上两个移动镜头、运动模糊开启的画面，**十组最终 PNG 和中间 RGBA16F 四通道全部逐像素相同**。新增前景测试物在墙后被挡住，移到墙前可见；把测试物挂在全屏物体下仍能正确处理；窗口在 960 × 600 与 1440 × 900 切换时两类目标状态均符合预期。[实机逐通道与深度读回](replay.json) · [静态主街](views/art-a-street-after.png) · [移动主街](views/motion-art-a-street-after.png)
