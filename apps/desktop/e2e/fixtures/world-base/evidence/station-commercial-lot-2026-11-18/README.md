# 站区后街商业地块

Kenney 的办公楼落在 station-office 地块。它沿用现有 10.10 × 10.00 米台基与八级入口台阶，正面距台阶 0.22 米。站区另一个低层住宅、拉克港与北端原聚落仍使用各自的地块定义。商业楼体由一个网格、一个双面站区色阶材质和一个 512 × 512 原作者图集组成，共 1,704 个三角形。现有台基、楼体与台阶属于背景建筑。

在 fixture 运行以下命令可准备原包与核对本机的三个文件。正常场景通过既有的 /city-assets/ 路由载入外部贴图依赖。

```bat
node scripts\prepare.cjs
node scripts\prepare-city.cjs --verify
```

本机从作者的临时签名 URL 取得 4,096,974 字节 ZIP，与清单固定 SHA-256 一致。二次离线核对通过，篡改测试中的图集被拒绝。CPU 装配保留所有实际 mesh、世界变换和拾取逻辑，禁止申请 WebGL 画布。普通初始化走到场景就绪，预烘焙命中 26 项，规划射线 0。22 处平面九点全部命中，另 4 处按原曲面规则贴合；没有发现遮挡这 26 项的新物体。第二轮旧包与本包的贴花数组逐项相同。先前针对 f608c8ae 的 RTX 3060 地面试照使用同一个楼体包围盒；第二轮整合后的图像与帧时另行采集。 [几何、来源与逐枚承托数据](receipt.json) · [作者与文件哈希](../../city-assets.json)
