# C酱 第 12 轮：洗衣店前材质主次（三项）

云端 SwiftShader 960×600、1.6 m 眼高；道具仍是替身（红箱即塑料箱替身），真实素材效果以林离本机为准。

看了林离 C11 的 24/23/21 真实图，整体判断：服务角（23）卷帘、箱筐、碎石尺度已经成立，这轮不动；
问题集中在洗衣店前（21/24）——一大片无纹理的浅色台面、店内白墙白机器白顶、墙上米级大圆纹，三者都是「白对白」没有主次。

1. **台面**（`city.js` foundation）：原来压顶是整块 0.09 m 的浅色 `M.plain` 平板，覆盖整个地块顶面，
   眼高看就是一张空白板。改为整块用 `M.concrete` 世界 UV 1.2 m 的铺装、中暖灰 #b8b1a3，只在四边留 0.2 m 浅色压顶。
   顶面高度不变（道具 supportY = top+0.02 仍贴地），压顶条高 5 mm。
2. **店内层次**（`city-apartments.js` 洗衣店 + `city.js` 店玻璃）：后墙 #f6efe2 → 灰青瓷砖色 #86aaa3，加深灰地面 #8d969a；
   店玻璃 uOpacity .14 → .08（掠射时的菲涅耳反射不变）。白色洗衣机和暖色灯条现在落在有颜色的背景前，见 `laundry-glass-before-after.png`（左 C11 右本轮）。
3. **墙面大圆纹**：城镇公寓墙的 plaster UV 3 m/张 → 1.5 m/张，共享贴图的污渍从米级圆环变成墙面颗粒。没有新纹理（city 仍断言不生成纹理）。

保护对照：04 店内与 C11 逐像素相同；01 街道只有樱花树冠/花瓣动画位置差（差异图集中在树冠），城镇改动不在画面内。
没有改 shader、太阳、天空、烘焙；没有加光。布局没有需要林离改的。

验证：`node scripts/verify.mjs`，Linux 20 步全部 code 0，1507/1507。
