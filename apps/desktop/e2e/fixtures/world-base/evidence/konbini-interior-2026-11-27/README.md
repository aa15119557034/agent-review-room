# X-51 · ひだまりマート室内

七组 Blender 模型接入车站 W1 的原店铺坐标。货架两面摆货，饮料和即食冷柜在后墙，收银台靠左，杂志架在进门右手边。货架、冷柜、收银台和杂志架沿用原来的碰撞占位。自动门、地板、窗框和入口台阶仍由车站场景管理。实际门洞中心为店铺局部 `x=1.0`，宽 `2.2 m`。房间前墙碰撞体和室内相机读取同一入口，原入口处的隐形阻挡已修正。[W1 平面与动线](W1-layout.png)

店内灯条和墙面的光改为冷白。主街玻璃门窗和北侧窗分别向各自面向的路面洒光，共用原有的路面采样与合批。可用 `?shopspill=off` 检查洒光的影响。`?time=night` 使用低强度蓝色月光，与原来的傍晚预设分别拍摄。

## 评审修订

夜间提高 W1 橱窗内上部的冷白照明，靠窗路面光池增亮。B 机位固定取样中，窗面较暗区域的亮度 P10 由 171.6 升至 234.9，店前路面光池的 P50 由 161.0 升至 211.9，均用 8 位 RGB 截图计算。[亮度取样](night-lighting.json)

W1 正面夜间的贴地投光深度从 6.2 米增至 7.9 米，光斑越过盲道向街边渐隐。同机位、同一组合场景的外侧人行道亮度中位数从 100 升至 146，满分 255。傍晚和北侧橱窗沿用原来的投光参数。[B 夜间 · 改动前后的门前光](B-night-spill.jpg)

室内换为灰蓝地砖，货架底部和靠墙地面分两档压暗。常见商品高约 10–18 厘米，单份布丁高约 9–11 厘米。三组货架展品从 580 件增至 1,266 件，冷柜展示面从 200 件增至 360 件。

## 实测

傍晚和夜间均从门外沿中间通道走到冷柜前，再返回门外。踏进店后双脚位于 `y=0.30 m` 的地板，沿通道在冷柜前 `z=-10.58 m` 停住。两轮场景均无页面或 WebGL 错误，启动时使用对应场景的烘焙贴花。[傍晚记录](evening-walk.json) · [夜间记录](night-walk.json)

RTX 3060 Laptop GPU 的 1440 × 900 冻结画面，以 `7886e7c9` 为基线，逐轮与新版交错运行。两版锁定相同的 B 和入口相机位姿，每轮预热 60 帧并记录 118 个有效 GPU 样本。下表为三轮 GPU P95 中位数，单位 ms。新版四项均低于 16.7 ms，相对基线的增加量均在 1.5 ms 以内。[交错顺序、每轮结果和原始帧时](gpu-timing-paired.json)

| 时段和机位 | 底分支 | 新版 | 新版 − 底分支 |
| --- | ---: | ---: | ---: |
| 傍晚 B | 15.38 | 15.18 | −0.20 |
| 傍晚入口 | 15.47 | 15.43 | −0.04 |
| 夜间 B | 15.60 | 15.33 | −0.27 |
| 夜间入口 | 15.55 | 15.26 | −0.29 |

室内着色与卡通光照共用一次店内边界判断，留住原有窗内亮度。夜间场景中的 PointLight 和 SpotLight 均为零，门前冷白光使用贴地加色面片。组合场景实拍确认 W1 两台原贩卖机与机脚投光正常。[新版傍晚与夜间](B-final-evening-night.jpg)

## 复现

在准备好本地依赖的 fixture 目录启动 `node scripts/art-preview.cjs serve 56353`。设置以下环境变量，再以 Electron 运行 `scripts/konbini-evidence.cjs`。

| 环境变量 | 用途 |
| --- | --- |
| `X51_KONBINI_TARGET` | `http://127.0.0.1:56353/` |
| `X51_KONBINI_OUTPUT` | 保存截图或原始 GPU 样本的本地目录 |
| `X51_KONBINI_MODE` | `capture` 拍照并测试出入店，`timing` 测量 GPU 帧时，`all` 连续运行两项 |

截图采用 1440 × 900 与固定场景时钟。步行探针从门外触发滑门，沿中间通道行走，检查后墙冷柜的阻挡，再从入口走出去。帧时模式在每个机位预热 60 帧，以 WebGL GPU timer query 累计每帧绘制耗时，分别统计三轮 P95。
