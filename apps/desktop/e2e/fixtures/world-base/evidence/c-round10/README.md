# C酱 第 10 轮：店内残余 AO 横带 + 正午局部自发光

云端 SwiftShader 960×600；道具仍是替身（见 `../c-round9/README.md`），本轮不涉及卷帘。

## 店内两道横带：根因
第 9 轮每个采样的权重是 `up*back` = 两个余弦相乘。在直角墙角，像素离折线距离 s、采样点在另一面上距离 t 时，
up = t/L、back = s/L，乘积 st/L²：**折线正中为 0**，在 s≈t 处最大。t 由采样的屏幕半径决定，
于是两个半径（0.4/0.9）各在墙上画出一道离开折线的暗带，中间留一道亮缝——就是林离量到的 y295/y313 两道、y304 缩小。

## 修法
遮蔽只用接收面的余弦 `up`（墙角正中最暗，离开后单调变浅）；采样面的朝向只当门槛：
`smoothstep(-0.3, -0.05, dot(n_s, -v̂))`。站在墙前的信箱/招牌正面背对后墙，dot≈-0.5～-1，仍被挡掉，不回到第 8 轮的光环。
系数 2.0（直角墙角约一半采样落在另一面，up≈0.9）。

同 ROI（960 下 x180..286，对应林离 1440 下 x270..429）每行 off−on 平均灰度：
y185 16.4（顶棚/后墙折线）→ y188 5.3 → y192–202 约 8–9.6（招牌顶与后墙的接触）→ y205 4.1 → y209 0.4 → y217 约 3（下一处接触）。
即每处接触各一道从折线开始单调变浅的阴影，不再有「一道折线两条带」。招牌是否贴墙我没在 GPU 上量深度，若林离判断它离墙较远、这道仍不该有，请告诉我。

已知小问题：顶灯灯条本身也被 AO 压暗约 15 级（AO 只看深度，分不出自发光面）；按亮度排除会误伤日照白墙，这轮没处理。
