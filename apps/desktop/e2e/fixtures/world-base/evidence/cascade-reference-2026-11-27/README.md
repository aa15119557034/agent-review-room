# 峡谷瀑布复拍

预览中展开「全岛地面抽样」，选「峡谷瀑布」或「瀑布岩岸」。画面沿用原峡谷约 113 米的落差。参考图里浅滩透出的暖色岩层、深蓝水道、碎浪边和岩台上的灌木簇用在了原场景的构图里。

- [峡谷全景对照](overview-comparison.jpg) 和 [岩岸近景对照](pool-comparison.jpg) 使用同一机位，左为基线 `e3e9f1c0`，右为本 PR。
- [岩台叶簇近景](leaf-detail.jpg) 展示半山岩台上交叠的三株灌木和短草。[傍晚复拍](evening.jpg) 使用与全景对照相同的相机。
- [采样记录](capture.json) 记录机位、资产落点、WebGL 检查和港镇对照结果。Electron 以 1440 × 900 渲染，动画固定在 5 秒。

水色由原地形深度和三座岸边石台的入水边缘决定。与山体连接的第四座石台位于半山，供叶簇生长，原崖面在接缝附近补了局部接触阴影。四座岩台均由 Blender 制作。两款灌木各由 48 片有厚度的弯折叶片组成，短草沿用项目里逐叶建模的 Blender 草簇。32 株植被分七组布置，根部以原地形高度采样或岩台的向下射线校验。

Blender 5.2.2 后台重导验证岩台和灌木 GLB 逐字节一致。世界地形高度、河道路径和碰撞数据沿用原场景。此轮验收为画面与加载检查，GPU 帧时未重新测量。
