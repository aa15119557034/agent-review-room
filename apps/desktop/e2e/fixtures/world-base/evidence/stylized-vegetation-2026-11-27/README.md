# X-51 植被样板实拍

- [站外草地](./station-comparison.jpg)使用交接机位，站区局部坐标 `(66.8, 119.1)`、朝向 `273°`。左图来自 `0cea32c5`，右图是本次样板。两个画面都冻结在傍晚。
- [针叶树细节](./cedar-detail.jpg)和[阔叶样板](./grove-comparison.jpg)对照本轮草模与本次样板。右图可见更大的树冠色块，同时阔叶近景仍能看到个别内层硬边。
- [站外机位明度图](./whetstone-value.png)使用 Whetstone 的 `look.py`。按 P2/P50/P98，原图为 51/108/223，样板为 53/109/223。

实际用 Blender 5.2.2 重新打开源文件，读取 11 个独立资产场景与一张打包图集。用[导出命令](../../assets/station-foliage-2026-11-27/README.md#编辑后导出)从源文件重导 11 个 GLB，逐个比对了顶点属性、索引、材质和图像数据，均与场景里使用的 GLB 一致。

预览在 Electron 1440×900、RTX 3060 Laptop GPU、ANGLE D3D11 下运行，加载错误和资产尺寸警告均为零。阔叶 A/B、针叶的近远景切换均同时处理了实体和叶卡批次。关闭植被后，交接机位的 PNG 与 `31fccef9` 同条件截图逐字节一致。

[冒烟测量](./checks.json)记录了 A / E / G 三个固定机位。每个机位预热 60 帧，取得 118 条有效 GPU 计时，P95 为 10.28 / 11.26 / 11.77 ms。正式验收仍需同批次对照并取三轮中位数。
