# X-51 植被样板实拍

- [站外草地](./station-comparison.jpg)使用交接机位，站区局部坐标 `(66.8, 119.1)`、朝向 `273°`。左图来自 `0cea32c5`，右图是本次样板。两个画面都冻结在傍晚。
- [针叶树细节](./cedar-detail.jpg)和[阔叶样板](./grove-comparison.jpg)对照本轮草模与本次样板。右图可见更大的树冠色块，同时阔叶近景仍能看到个别内层硬边。
- [站外机位明度图](./whetstone-value.png)使用 Whetstone 的 `look.py`。按 P2/P50/P98，原图为 51/108/223，样板为 53/109/223。

实际用 Blender 5.2.2 重新打开源文件，读取 11 个独立资产场景与一张打包图集。用[导出命令](../../assets/station-foliage-2026-11-27/README.md#编辑后导出)从源文件重导 11 个 GLB，逐个比对了顶点属性、索引、材质和图像数据，均与场景里使用的 GLB 一致。

预览在 Electron 1440×900、RTX 3060 Laptop GPU、ANGLE D3D11 下运行，加载错误和资产尺寸警告均为零。阔叶 A/B、针叶的近远景切换均同时处理了实体和叶卡批次。关闭植被后，交接机位的 PNG 与 `31fccef9` 同条件截图逐字节一致。

[第一轮冒烟测量](./checks.json)记录了 A / E / G 三个固定机位。每个机位预热 60 帧，取得 118 条有效 GPU 计时，P95 为 10.28 / 11.26 / 11.77 ms。正式验收仍需同批次对照并取三轮中位数。

## 评审修订

- 阔叶缩小了内层支撑体，连接主枝上的大块树冠，顶层偏暖绿、底层偏冷绿。两种树的近景宽高比为 0.74 和 0.68，三角面数均为近景 816、远景 306。用 Blender 5.2.2 重开 11 个资产场景并重导，逐个比对渲染数据一致。[阔叶实拍](./review-grove.jpg) · [倾向分层的树冠上色案例](https://xun.archi/ecovision)
- 站外短草与地面共用色场，草叶更窄，10–25 米逐渐并入地面色。站外短草从 168,048 降至 161,802 个三角面，岛上原有 21,022 个草花落点逐点一致。交接原机位的全画面 P50 从 109 升至 118，阴影下的草底仍有偏平的区域。[交接机位](./review-station.jpg) · [草地中段](./review-lawn.jpg) · [明度对照](./review-value.png) · [用地面色给草着色的开源示例](https://github.com/dedekpo/stylized-scene)
- 修剪树篱改为连续的高低起伏，转角、树脚补第二层低灌木。站边树篱 200 → 208 段，新增 48 株低灌木。逐株检查步道、道路、建筑保护范围，无失败。[站边树篱](./review-hedge.jpg) · [东缘近照](./review-hedge-corner.png)
- 岛外远处橙树的射线命中普通阔叶远景。临时关闭植被的空中透视后，橙色消失。修订降低了植被的雾色混合权重，保留傍晚远近变化。[空中透视诊断](./review-orange-diagnostic.jpg)

Electron 1440×900 冻结傍晚实际加载，场景和控制台无错误，模型尺寸无警告。两类阔叶与针叶的实体和叶卡批次同时切换。关闭植被后与第一轮关态原机位对照，1,296,000 像素中 58 个发生差异，各通道最多相差 1 级。

对 `047db449` 在同一批次交错跑三轮关 / 开，RTX 3060 Laptop GPU，固定傍晚，预热 60 帧、每轮每镜 118 个有效 GPU 帧。取三轮 P95 的中位数，A 主街 10.84 → 11.30 ms，E 港镇 10.63 → 12.21 ms，G 铁路 11.86 → 12.28 ms。[逐帧数据](./review-timing.json)

## 平涂草底与树篱新色

- 草地开阔处改为连续地色，短叶留在步道肩和种植边缘。共 71 组、1,170 片短叶、3,510 个三角面。颜色和密度共用 5.8–7.2 米过渡，原有的 21,022 个岛上草花落点逐点一致。交接机位草地同一裁切区域，亮度中位数从上轮 116.0 降为 103.4，平均 HSV 饱和度从 0.201 升至 0.291。[参考、前后原机位对照](./anime-lawn-review.jpg)
- 树篱改用暖绿冠顶、冷绿侧面和底部。Blender 重导后，树篱只变化了顶点色，其余 10 个 GLB 的渲染数据逐项一致。重导树篱进入实时场景，用同一份草地代码和相机测过配色 A/B，加载无错误。[参考与站边转角实拍](./anime-corner-review.jpg)
- 这轮定的是草底、边缘草簇与树篱的用色。参考里的草地受光形状更丰富，站外既有的硬亮带在新图上仍然明显。树冠与树篱的统一卡通色阶和轮廓线还需场景样板验证。

## 草底颜色诊断

在 `26b33a06` 上沿用冻结傍晚、1440×900，交接原机位和东缘转角各拍四组。关闭全局调色走现有的 `?grade=off`。关闭空中透视时，仅在诊断进程把上游高度雾密度和场景模型的雾混合权重设为零，天空风格开关仍为 1。Electron 场景、控制台和 WebGL 读数均无错误。

| 原机位前景草底，同一像素区域 | 平均 HSV 饱和度 | 亮度 P50 |
| --- | ---: | ---: |
| 原样 | 0.291 | 103.4 |
| 关闭全局调色 | 0.489 | 110.7 |
| 关闭空中透视 | 0.291 | 103.4 |
| 两个都关 | 0.489 | 110.7 |

全局调色会压低这块前景草底的饱和度。近景树篱的采样反向变化，单关全局调色时饱和度从 0.497 降至 0.437。空中透视对远处楼体变化明显，近景树篱和草底的平均 RGB 变化不超过 0.2 级。转角地面斜边在两个效果都关闭时仍可见。

## 傍晚绿色保护

沿用后处理已有的黄绿至青绿软遮罩，把傍晚的 `greenCut` 从 4 降至 1.3333。调色亮度曲线和午后参数未改。

Electron 1440×900 冻结傍晚。常规入口读取修订参数后，用同一份场景的原参数复拍，另开 `?grade=off` 页面作对照。交接机位同一块草底的平均 HSV 饱和度为原样 0.291、新版 0.481、关调色 0.489。新版距关调色仅 0.008，草底亮度 P50 从 103.43 到 103.50。A–H 八镜共 9,373,428 个非绿采样像素，每通道最多差 1 级。划区采用关闭调色的画面，保守排除 66°–167° 色相和极低饱和度像素。

## 草地冷暖分区和树篱配色

草地用站区坐标内的低频色场画出倾斜的树影形状。受光草底偏暖黄绿，阴影区用深蓝绿。地面和短草共用色场，单独变化颜色通道，原覆盖边界和草簇分布照旧。71 组站外短草、1,170 片短叶和岛上 21,022 个草花落点均一致。

冻结傍晚的交接机位，前景同区域的青绿像素比例由 0.19% 升至 34.75%（色相 135° 至 184°，饱和度至少 38/255），亮度 P10、P50、P90 从 98.86 / 103.50 / 105.93 变为 57.56 / 81.82 / 114.28。A 主街全图每通道最大差不超过 1 级。截图无加载及 WebGL 错误。[参考与交接机位](./warm-cool-handoff.jpg) · [参考与 A 主街](./warm-cool-art-a-street.jpg) · [取样数据](./warm-cool-audit.json)

树篱只改顶点色，冠顶留鲜绿，侧面和基部着冷绿。Blender 重开后 11 个 GLB 从源文件重新导出，渲染数据与场景接入版本一致。同光照独立 A/B，近照受颜色影响像素的中位色相从 70.6° 到 105.9°。[交接机位和近照](./warm-cool-hedge.jpg)

## 草底树影复拍

把阴影提亮成青绿，受光区向黄绿靠。加入一层中频变化切开边缘，草底和短叶共用两级色调过渡。沿用冻结傍晚，交接机位复拍，并从另一片草地取第二组视角。站外短草仍为 71 组，岛上 21,022 个草花落点逐点一致。

交接机位固定前景取样区的亮度 P10 从 57.56 升至 85.04。用色相 112°–185°、饱和度至少 38/255 的青绿像素估算，新版占取样区 36.26%。这个比例用于对照画面色块。A 主街两轮截图逐像素相同，场景加载和 WebGL 无错误。第二机位仍能看到此前记录的硬亮带。

## 草地硬亮带

第二机位单因素复拍。关闭地形接缝和岛面混合，亮带不变。只停地面接收阴影，亮黄扩展到日照区。只停太阳直射，亮带消失。逐项关闭全局调色、三段色阶、轮廓高光或阴影硬切都仍可看到亮带。[原样与两个光照开关](./lawn-light-diagnostic.jpg)

在草坪和短叶着色时，按既有草地覆盖比例渐隐直射漫反射，草地的手绘色场提供暖光和青绿阴影。两处 1440×900 冻结傍晚的取样区内，纯黄像素分别从 31,213、21,345 降为 0（R > 210、G > 195、B < 40）。A 主街截图逐像素相同。交接机位的草底亮度 P10 仍为 85.04，原有岛上 21,022 个草花落点逐点一致。另一片草地的步道旁仍有较淡的暖光。
