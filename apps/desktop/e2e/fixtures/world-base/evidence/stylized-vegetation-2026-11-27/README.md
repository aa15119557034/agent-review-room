# X-51 植被样板实拍

- [站外草地](./station-comparison.jpg)使用交接机位，站区局部坐标 `(66.8, 119.1)`、朝向 `273°`。左图来自 `0cea32c5`，右图是本次样板。两个画面都冻结在傍晚。
- [针叶树细节](./cedar-detail.jpg)和[阔叶样板](./grove-comparison.jpg)对照本轮草模与本次样板。右图可见更大的树冠色块，同时阔叶近景仍能看到个别内层硬边。
- [站外机位明度图](./whetstone-value.png)使用 Whetstone 的 `look.py`。按 P2/P50/P98，原图为 51/108/223，样板为 53/109/223。

实际用 Blender 5.2.2 重新打开源文件，读取 11 个独立资产场景与一张打包图集。用[导出命令](../../assets/station-foliage-2026-11-27/README.md#编辑后导出)从源文件重导 11 个 GLB，逐个比对了顶点属性、索引、材质和图像数据，均与场景里使用的 GLB 一致。

预览在 Electron 1440×900、RTX 3060 Laptop GPU、ANGLE D3D11 下运行，加载错误和资产尺寸警告均为零。阔叶 A/B、针叶的近远景切换均同时处理了实体和叶卡批次。关闭植被后，交接机位的 PNG 与 `31fccef9` 同条件截图逐字节一致。

[第一轮冒烟测量](./checks.json)记录了 A / E / G 三个固定机位。每个机位预热 60 帧，取得 118 条有效 GPU 计时，P95 为 10.28 / 11.26 / 11.77 ms。正式验收仍需同批次对照并取三轮中位数。

## 评审修订

- 阔叶缩小了内层支撑体，连接主枝上的大块树冠，顶层偏暖绿、底层偏冷绿。两种树的近景宽高比为 0.74 和 0.68，三角面数均为近景 816、远景 306。用 Blender 5.2.2 重开 11 个资产场景并重导，逐个比对渲染数据一致。[阔叶实拍](./review-grove.jpg) · [倾向分层的树冠上色案例](https://xun.archi/ecovision)
- 站外短草与地面共用色场，草叶更窄，10–25 米逐渐并入地面色。站外短草从 168,048 降至 161,802 个三角面，岛上原有 21,022 个草花落点逐点一致。交接原机位的全画面 P50 从 109 升至 118，阴影下的草底仍有偏平的区域。[交接机位](./review-station.jpg) · [草地中段](./review-lawn.jpg) · [明度对照](./review-value.png) · [用地面色给草着色的开源示例](https://github.com/dedekpo/stylized-scene)
- 修剪树篱改为连续的高低起伏，转角、树脚补第二层低灌木。站边树篱 200 → 208 段，新增 48 株低灌木。逐株检查步道、道路、建筑保护范围，无失败。[站边树篱](./review-hedge.jpg) · [东缘近照](./review-hedge-corner.png)
- 岛外远处橙树的射线命中普通阔叶远景。临时关闭植被的空中透视后，橙色消失。修订降低了植被的雾色混合权重，保留傍晚远近变化。[空中透视诊断](./review-orange-diagnostic.jpg)

Electron 1440×900 冻结傍晚实际加载，场景和控制台无错误，模型尺寸无警告。两类阔叶与针叶的实体和叶卡批次同时切换。关闭植被后与第一轮关态原机位对照，1,296,000 像素中 58 个发生差异，各通道最多相差 1 级。

对 `047db449` 在同一批次交错跑三轮关 / 开，RTX 3060 Laptop GPU，固定傍晚，预热 60 帧、每轮每镜 118 个有效 GPU 帧。取三轮 P95 的中位数，A 主街 10.84 → 11.30 ms，E 港镇 10.63 → 12.21 ms，G 铁路 11.86 → 12.28 ms。[逐帧数据](./review-timing.json)
