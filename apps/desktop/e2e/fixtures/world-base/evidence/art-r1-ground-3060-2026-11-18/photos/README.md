## 局部核验

- **A 的碰撞。** 从当前放车代码、量产车型尺寸与原生 `Physics.resolve` 复算。车体碰撞盒宽 1.555 m、长 3.530 m。0.30 m 半径胶囊横向进车身止于站区 x=1.0225，沿车身进车尾止于 z=14.61。在仅加入这辆新车的碰撞场景，路中 x=0 和东人行道 x=3.8 两条 10 m 直线均无推挤。全场第三和第一人称步行由本轮帧时报告记录。[碰撞票据](van-collision.json)
- **B 的店内和门前。** 窗后商品层板样区 196 × 82 像素，16,072 个像素中 MAX RGB 跨版差大于 8 的有 0 个，显示亮度中值 187.81 → 187.73。区域的红通道中位比蓝通道高 40 级，前后相同。门口瓶箱区有 76.37% 像素差大于 8；门槛暖光区亮度中值 117.75 → 156.06。窗后原货架和玻璃分别来自 `shopsA/intKonbini.js` 的三排货架与 `shopsA/konbini.js` 的前窗玻璃。
- **C 的光源、花坡和管线。** 未贴纸墙区中值 51.86 → 46.30，蓝减红通道的中位差 4 → 13；近处暖灯区亮度中值均为 212.20。右缘坡面样区 169 × 103，前后均有 3,240 个像素匹配亮粉色，MAX RGB 差大于 8 的像素为零。两条 6.20 m 横管高出廊地 0.46 / 0.64 m，于门洞前经过。站区 x=−2 的 1.03 m 门洞被横跨全宽，x=2 的门洞有 0.815 m 被覆盖，x=6 的门洞未受影响。这三扇是背景建筑的固定门面。[管线及门洞投影坐标](C-pipe-doors.json)
- **D 的告示与灯箱。** 新增 27 张窗面/两侧贴纸和一面价格折叠牌。新窗贴样区 27.58% 的像素差大于 8，折叠价格牌样区占 90.28%。灯箱样区的显示亮度中值均为 118.07，蓝减红中位差均为 88。原星形海报的旧边界接近 x=1220–1311、y=362–461；该范围 96.30% 像素差大于 8。[各区边界及图像统计](image-measurements.json)

## 对照 #252 的七项

| 项 | 第一轮结论 |
|---|---|
| 明暗结构 | B 的门口暖光增宽，C 的后墙与环境更冷更暗。C 右缘的高亮花坡仍偏离后巷参考。 |
| 配色 | B 集中出一块高饱和招牌，D 仍以青灰为主。A 左侧多色旗、C 远处粉花仍占注意力。 |
| 轮廓 | 静止时车身、货架、网柱与价格牌轮廓可读。静帧仅用于判断固定镜头。 |
| 密度 | 四镜接近参考的主要进步是沿街旗与停靠车辆、店门外摆、后巷网架箱子和洗衣店窗贴。C 管线穿门破坏造型合理性。 |
| 光源 | B 保留暖亮店内，冷色街面与门槛暖光可分辨。C 暖灯样区保持原亮度。四张 R1 单幅中 RGB 三通道同时 ≥250 的像素，A/B/C/D 分别为 57/64/0/0；屏幕码值仅反映成片。 |
| 性能 | 见同一证据目录的独立 RTX 3060 四镜和两种步行计时。 |
| 方向 | 四镜的空间和陈列总体更接近；管线穿门、亮粉花坡和旧贴花替换仍应点名。 |
