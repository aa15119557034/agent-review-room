# C酱 第 18 轮：近景绿篱的迷彩斑块

只改城镇自己的 foliage 克隆（`city.js`），车站的 foliage 不动。草、花、砾石、墙材质、店招、周转箱都不动，几何也不动（镇边 29,933）。云端 SwiftShader 960×600。

## 原因

第 16 轮我把叶团明暗从 +10% / −14% 加到了 +16% / −26%。上游叶团的边缘过渡宽度下限只有 0.03（Worley 单位），近看边缘很硬。两者加在一起，近景绿篱就成了一块块硬边色斑，像迷彩。

## 改法

- 叶团明暗退回上游原值：+10% / −14%。
- 边缘过渡宽度的下限从 0.03 放宽到 0.14，叶团之间改成柔和过渡。远处本来就按 `fwidth` 放宽，不受影响。
- 第 16 轮的橄榄去饱和保留。
- 三个参数放进 uniform `uTownLeaf`（x 亮部，y 暗部，z 边缘下限），挂在材质的 `userData.townLeaf` 上，方便对照。program key 不变。

## 对照

`24-hedge-c17-b-c.jpg` 和 `21-hedge-c17-b-c.jpg` 都是裁切图，从左到右三组参数：

| | 亮部 / 暗部 / 边缘下限 | 效果 |
|---|---|---|
| C17 | .16 / .26 / .03 | 硬边迷彩 |
| **B（本轮采用）** | .10 / .14 / .14 | 斑块退成柔和的叶团起伏；体积和根部接触阴影由光照和 AO 保留 |
| C | .07 / .11 / .22 | 几乎没有叶团，又回到第 15 轮那种「光滑的一整块」，不采用 |
