# 地面机位的道具视锥裁剪 · RTX 3060

这版按 256 米分组绘制灯塔、立石、岩块和风动树。树木包围球额外留 3 米，覆盖风动。相机转身时使用已在内存里的实例，水面反射按自己的反射相机裁剪。资源加载、地形精度、分辨率、材质和后处理沿用对照版。前后对比只取地面视角。

## 整帧实测

四次独立启动，依次运行原版、分组、分组、原版。固定机位各连续采样约 10 秒，第三人称和第一人称各按住真实 W 键约 3 秒，实走 9.75–9.86 米。所有轮次用相同的 Chromium 启动参数，窗口在采样起止均报告页面可见。表内为平均 FPS / P95 帧时（毫秒）。

主街原版两轮有明显波动。便利店四批都合成原对象时只有 4 次绘制，空间分组增加到 29 次，两个分组轮次的 P95 均达到 30.7 毫秒。此版留作性能实验，共享美术分支继续采用原绘制路径。

早先一次窗口被覆盖期间约每秒只采到一帧，步行只移动 0.33 和 0.37 米，触发校验失败。该次结果已排除。随后用相同的防后台节流设置重新跑完全部四轮。四轮的 273 个本地 HTTP 请求均有服务端和接收端配对证据。

## 重放

`tools/prove-cells.cjs` 依次接受场景目录、Electron 可执行文件、含有 `scripts/acceptance-transport.cjs` 的验收目录、新建的输出目录、场景提交号和 `ground` 或 `lake`。地面和湖面分别使用上面的裁剪提交和联验提交。`tools/timing-ground-visible.cjs` 依次接受 Electron 和新建的 artifacts 子目录名，环境变量 `WORLD_FIXTURE`、`AUDIT_FIXTURE`、`TESTED_SOURCE` 分别指向被测场景、验收目录和提交号。启动前须准备好同版场景资产。
