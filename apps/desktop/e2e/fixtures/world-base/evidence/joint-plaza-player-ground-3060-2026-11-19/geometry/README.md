## 复核

`node verify.cjs <联合 fixture 绝对目录>` 用原始数据、固定提交和已有最终资产几何复算摘要。完整装配的原始回执为 `raw.json.gz`，第二次装配的各交点、材质及物理查询在 `ground-rays.json`。项目原有最终验收仍是比较基线。

复跑两次真实场景装配可用 `node replay.cjs <联合 fixture 绝对目录> <Electron 可执行文件> <新输出目录>`。运行前在联合树完成正常 prepare，保留同一固定环境与最终资产。回执记录 CPU 几何行为与选中地面，帧时间、实际像素和 OS 输入由单独的原生捕获记录。
