# C酱 第 13 轮：四区道具材质收边

云端 SwiftShader 960×600、1.6 m 眼高；塑料箱/卷帘仍是替身（红箱），真实效果以林离本机为准。物件数量和位置都没动。

1. **分类桶颜色**：林离复用的 `H.P.bins` 套件色（#6b8f6b/#5a7fa8）在 1.6 m 近看像玩具。
   新 `townSortingBins`（city-apartments.js 导出）几何、尺寸、标签图集、0.5 m 间距与套件完全相同（不调 rng，套件 n=2 时本来也不用），
   只换克制配色：桶身 #62786a/#55687f，桶盖再深一档 #4c5f53/#43536a 给顶边。洗衣店和服务角两处都用它；碰撞/实例记录未改。
2. **楼墙圆纹**：根因是上游 plaster 贴图本身画了 30 条抹刀弧线（tex.js:37），UV 缩小只是把圈变小（林离 C12 回验仍可见）。
   墙面改用同套件的 `M.concrete`（只有柔和色斑和颗粒，同为近白底色，墙色调不变），UV 回到 3 m/张。24 右墙已无圆纹。
   注意：21 里远处 5F 灰蓝楼向阳面的色斑比较明显，像旧水泥墙；若你看着太脏，告诉我改 UV 或换回纯色。
3. **台面共面侧带**：铺装板 X/Z 各缩 1 cm（每边 5 mm），侧面完全藏在四条压顶后面，不再与压顶外侧共面。

保护：04 店内与 C12 逐像素相同；01 只有樱花动画差。没改 shader/光/太阳/天空/烘焙，没加新模块。

验证：`node scripts/verify.mjs`，Linux 20 步全部 code 0，1507/1507。
